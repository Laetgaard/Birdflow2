Birdflow Homepage Redesign — Full Replit Plan
Objective

Redesign only the Birdflow homepage / to closely reproduce the supplied desktop and mobile Figma/PDF designs.

The redesign must preserve Birdflow’s existing functionality and must not visually redesign any other page.

The two supplied designs should be treated as independent responsive references:

Desktop PDF = desktop source of truth.
Mobile PDF = mobile source of truth.
Tablet = intentionally interpolate between them.

The existing content hierarchy includes the hero, workflow, customer experience, Birdflow expectations/features, product demonstration, pricing and footer.

9. Create homepage-specific design tokens

Instead of random colors throughout the stylesheet, define tokens.

Example:

.birdflow-home {
  --home-purple: ...;
  --home-blue: ...;
  --home-lime: ...;
  --home-cream: ...;
  --home-text: ...;

  --home-container: ...;
  --home-mobile-gutter: ...;
  --home-desktop-gutter: ...;
}

Use existing Birdflow colors if equivalent variables already exist.

Do not create a new global design system for this task.

10. Homepage root isolation

Wrap everything in something like:

<main className="birdflow-home birdflow-home-redesign">

Then scope styles appropriately.

The purpose is preventing:

h1 {}
button {}
section {}

from changing the rest of Birdflow.

Avoid new broad global selectors.

54. Comparison priority

Prioritize visual accuracy in this order:

1. Overall composition

Section heights and content distribution.

2. Typography

Size, line wrapping, font and weight.

3. Artwork

Scale and position.

4. Spacing

Margins, padding, gaps.

5. Shapes

Waves, button radii and section transitions.

6. Micro polish

Shadows, small alignment differences, decorative details.
