API ENDPOINTS (server-side)
- POST /api/subscriptions/create-checkout-session
  - Input: userId, plan_slug, optional coupon, success_url, cancel_url
  - Create/attach Stripe Customer (store stripe_customer_id)
  - Create Checkout Session for subscription with price, trial days if applicable
  - Return session.url to client
- POST /api/subscriptions/create-portal-session
  - Create Stripe Customer Portal session and return url
- POST /api/stripe/webhook
  - Secure webhook handler to process events:
    - invoice.paid
    - invoice.payment_failed
    - customer.subscription.created
    - customer.subscription.updated
    - customer.subscription.deleted
    - checkout.session.completed
  - Update users.subscription_status, subscription_id, subscription_price_id, trial_ends_at accordingly
  - Create local invoice records for billing page
  - Send transactional emails on subscription created/failed (use existing email service)
- GET /api/subscriptions/current
  - Returns current plan, trial status, next_invoice_date, invoice history
- POST /api/subscriptions/change-plan
  - Handle upgrade/downgrade logic and proration settings (use Stripe proration or set manual behavior)
- POST /api/subscriptions/cancel
  - Cancel at period_end or immediate (optionally)
- POST /api/subscriptions/resume
