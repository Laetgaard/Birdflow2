Add Page Management + Ecommerce System Integration

Implement the following features into the builder and published website:

1. Page Management in Builder

Add UI in the builder sidebar called “Pages”.

Allow users to:

Create new pages (name + URL path)

Rename pages

Delete pages (except the home page)

Adding a page updates builder_state.pages[] in Supabase.

When a page is added or renamed, update the navigation automatically.

2. Navbar Connection

The published website header should automatically generate navigation links from the builder_state.pages[] data.

The order of pages in the navigation should match the pages[] array order.

3. Ecommerce Pages

Automatically create the following pages when products exist:

/shop → product catalog showing all active products for that website_id

/shop/[productId] → product detail page with Add to Cart button

/cart → shopping cart page with items, totals, and checkout form

These routes should be generated in the Vercel publish process so the live site matches the builder preview.

4. Shopping Cart + Checkout

Use browser persistence (localStorage or cookie) for the shopping cart.

Support quantity change, remove item, and empty cart.

Checkout should create an entry in an orders table with status "pending".

Reduce stock on checkout server-side only if stock is available.

Prevent checkout if stock is 0 or negative.

5. Data + Security Requirements

Product and order reads on the published site use Supabase anon key + RLS enforced by website_id.

Product and order writes must go through authenticated API routes or server actions.

Service role key is only available server-side in Vercel, never client-side.

6. Architecture Constraint

Do not duplicate rendering logic between builder preview and published site.

The component rendering pipeline must be shared so the same components work in both contexts using builder_state.

After planning, explain how page creation will trigger navigation updates and how ecommerce-specific routes will be injected during the publish-to-Vercel flow.
