5. Component instances versus component definitions

How does Birdflow currently distinguish between:

A reusable component definition in the library.
An inserted component instance on a page.
Content overrides for that instance.
Design overrides for that instance.

Which behaviour do you want?

Option A — copied instance

Inserting a library component copies its tree. Future library updates do not affect existing sections.

Option B — linked instance

The section references a component definition and stores only local overrides. Updating the definition can update every linked instance.

Option C — hybrid

A component starts linked but can be detached into a local copy.

For AI-generated design systems, hybrid is usually strongest, but it is also significantly more work.
